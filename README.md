# The Common Agent Specification has moved

The Common Agent Specification is the base of the Common Agent Standards, and
its home is the Common Agent Standards repository:

https://github.com/CommonAgent/common-agent-standards/tree/main/common-agent

Its history, its site tools and its workflow moved there with it. Versions are
tagged there as `common-agent-v` followed by the version, such as
`common-agent-v0.26.0-draft`. The specification is published at
<https://commonagent.net/spec.html>.

This repository is archived. It keeps the text as it was at 0.26.0-draft, the
`v0.26.0-draft` tag and its release.
